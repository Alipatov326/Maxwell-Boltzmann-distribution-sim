# Maxwell–Boltzmann Distribution Simulation

A project on how elastic collisions produces the Maxwell–Boltzmann speed distribution.

## What this project does

- Compares four initial conditions across six gas presets.
- Measures approach to equilibrium using empirical CDF distance.
- Compares sample sizes across ten independent seeds.
- Examines temperature and molecular-mass scaling.
- Includes seven physics tests and optional plot/data exports.

## Key findings

- The reference nitrogen run (12,000 particles, 300 K, 60 sweeps, seed 42) approaches the theoretical distribution while conserving energy to floating-point precision.
- Across ten seeds, mean final CDF distances for 500, 2,000, and 8,000 particles are approximately 0.02884, 0.01921, and 0.00757.
- Speeds scale as the square root of temperature divided by molecular mass.
- Finite-sample fluctuations remain at equilibrium; individual distances need not decrease monotonically.

- `Maxwell_Boltzmann_Simulation.ipynb`: all Python implementation, tests, experiments, plotting, and analysis.

## Running this notebook

Upload the notebook to Google Colab, or open it in Jupyter with Python 3.10+. Run cells from top to bottom. The notebook requires NumPy 2.x and Matplotlib.

## Background and assumptions

Basic probability, calculus, and Python/NumPy are a must. The mathematical model and collision update are explained in the notebook. Positions do not determine collisions and sweep counts are not physical time. The model describes classical translational physics for equal-mass particles.
